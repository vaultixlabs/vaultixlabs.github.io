Términos de Servicio

Última actualización: 7 de noviembre de 2026 · Borrador — pendiente de revisión legal

Estos Términos de Servicio ("Términos") rigen el acceso y uso de Vaultix Gate y servicios relacionados (el "Servicio") proporcionados por Vaultix Labs ([razón social], "Vaultix", "nosotros"). Al acceder o usar el Servicio, la entidad o persona que acepta estos Términos en nombre de una organización ("Cliente") acepta quedar obligada por ellos. Si no estás de acuerdo, no uses el Servicio.

1. El Servicio

Vaultix Gate es una plataforma B2B de verificación de identidad biométrica. Proporciona detección de vida, coincidencia facial, inteligencia de dispositivo, puntaje de riesgo, panel de cumplimiento y herramientas de auditoría/evidencia, entregadas a través de un web component, una página de verificación alojada y una API REST. El Servicio está destinado a la verificación de identidad para onboarding de usuarios adultos.

2. Elegibilidad y cuentas

El Servicio se ofrece únicamente a empresas e instituciones reguladas. Debes proporcionar información de cuenta precisa, mantener las credenciales confidenciales y asegurar que el personal que accede al Servicio esté autorizado. Eres responsable de toda la actividad bajo tu cuenta.

3. Uso aceptable

Aceptas no:

  • Usar el Servicio con fines ilícitos o para verificar personas sin base legal;
  • Intentar eludir los controles de liveness, anti-spoofing, límites de tasa o seguridad;
  • Enviar datos biométricos de personas que no hayan dado consentimiento válido;
  • Realizar ingeniería inversa del Servicio salvo lo permitido por la ley aplicable;
  • Interferir con la operación del Servicio o degradarla.

4. Datos del cliente y custodia biométrica

Conservas todos los derechos sobre los datos que envías ("Datos del Cliente"), incluidos los metadatos de usuarios finales y referencias. Las plantillas biométricas generadas por el Servicio se cifran bajo claves controladas por ti; Vaultix nunca posee el material de claves. Eres responsable de tener una base legal — incluido el consentimiento explícito cuando se requiera — para todo procesamiento biométrico que inicies.

Las tarifas, rangos de volumen de verificaciones, condiciones de pago y cualquier manejo de excedentes se definen allí. Salvo indicación contraria, las tarifas se facturan por adelantado y no son reembolsables.
